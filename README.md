# Belajar Buat Web

Website portofolio pribadi saya, sekaligus tempat mengumpulkan semua proyek yang saya buat selama belajar web development.

**🔗 Lihat website:** [darmawanchandra.github.io/belajar-buat-web](https://darmawanchandra.github.io/belajar-buat-web/)

## Struktur Folder

```
belajar-buat-web/
├── index.html      → halaman utama (isi & struktur)
├── css/
│   └── style.css   → tampilan (warna, ukuran, tata letak, animasi)
├── favicon.svg     → ikon kecil di tab browser
└── proyek/         → (segera) setiap proyek punya folder sendiri
```

## Cara Membuka di Komputer

Klik dua kali file `index.html`, lalu website akan terbuka di browser. Tidak perlu instal apa pun.
